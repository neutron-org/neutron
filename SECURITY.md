# Security Policy

## Project Status

The original Neutron project has entered a wind-down phase. Ongoing maintenance and security updates are now exclusively managed by **Solva**. 

The canonical repository containing all current releases and security fixes is located at:
[https://github.com/solva-solutions/neutron](https://github.com/solva-solutions/neutron)

## Reporting a Vulnerability

If you discover a security vulnerability in Neutron, please do **not** file a public issue or submit a pull request to the original repository. 

Instead, please report it directly to the Solva security team via email at:
**[security@solva.solutions](mailto:security@solva.solutions)**

When reporting an issue, please try to include:
* A detailed description of the vulnerability and its potential impact.
* Steps to reproduce the issue.
* Any relevant versions or configurations affected.

The Solva team will review your report, acknowledge receipt, and coordinate any necessary fixes and disclosures through the [new canonical repository](https://github.com/solva-solutions/neutron).
